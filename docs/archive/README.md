# Documentation Archive

This directory preserves superseded plans and development checkpoints for
historical traceability.

Nothing in this directory is an active implementation plan. Current product
behavior, limitations, and priorities are documented in
[`../product/PRODUCT.md`](../product/PRODUCT.md).

Archived documents should not be edited to describe new work. Create or update
a current document instead, and retain the archive as evidence of the earlier
state.
